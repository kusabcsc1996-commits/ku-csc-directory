# 🌿 KU CSC Hub — ศูนย์รวมช่องทางติดต่อ มก.ฉกส.
### มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตเฉลิมพระเกียรติ จังหวัดสกลนคร

เว็บพอร์ทัลรวบรวมลิงก์ Facebook Pages, เว็บไซต์ทางการ และช่องทางติดต่อของทุกคณะ สโมสรนิสิต และหน่วยงานสนับสนุนการศึกษา มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตเฉลิมพระเกียรติ จังหวัดสกลนคร ออกแบบในสไตล์ Modern Glassmorphism สวยงาม ใช้งานง่าย และรองรับการแสดงผลบนทุกอุปกรณ์

---

## 🌟 จุดเด่นและฟังก์ชันการใช้งาน

### 1. เว็บที่ 1: สำหรับผู้ใช้ทั่วไป (`index.html`) — Read-Only
- **แสดงข้อมูลครบทั้ง 15 หน่วยงาน**: คณะวิชา, หน่วยงานบริการ, องค์กรนิสิต, สโมสรนิสิตคณะ
- **ภาพพื้นหลังส่วนหัว (Hero Background)**: ภาพแลนด์มาร์คซุ้มประตู มก.ฉกส. ท่ามกลางแสงตะวันและดอกเฟื่องฟ้า
- **เว้นพื้นที่ใส่แบนเนอร์และโลโก้ (Dedicated Slots)**: จัดวางพื้นที่สำหรับใส่แบนเนอร์และโลโก้ไว้อย่างสวยงามและเป็นระเบียบ
- **ระบบค้นหาแบบ Real-time (Instant Search)**: ค้นหาด้วยชื่อภาษาไทย, ตัวย่อภาษาอังกฤษ หรือคีย์เวิร์ด
- **ตัวกรองหมวดหมู่ (Category Filter)**: เลือกดูเฉพาะ คณะวิชา, หน่วยงานบริการ, องค์กรนิสิต หรือ สโมสรนิสิต
- **QR Code & คัดลอกลิงก์**: สแกนเพื่อเปิดบนสมาร์ตโฟนได้ทันที หรือกดคัดลอกลิงก์พร้อมการแจ้งเตือน Toast
- **โหมดมืด/สว่าง (Dark / Light Mode)**: สลับธีมได้ง่ายเพียงคลิกเดียว

### 2. เว็บที่ 2: สำหรับแก้ไขข้อมูลและเปลี่ยนรูปภาพ (`editor.html`) — Editor
- **เปลี่ยนรูปภาพพื้นหลังส่วนหัว (Hero Background)**: อัปโหลดจากเครื่องคอมพิวเตอร์ หรือใส่ลิงก์ URL
- **เปลี่ยนรูปภาพแบนเนอร์และโลโก้**: อัปโหลดจากเครื่อง หรือใส่ลิงก์ URL พร้อม Live Preview
- **ปุ่มเว้นว่างรูปภาพ**: สามารถลบรูปภาพออกเพื่อให้คงเป็นพื้นที่ว่างตามเดิมได้
- **แก้ไขข้อมูลหน่วยงาน**: แก้ไขชื่อภาษาไทย, ชื่อย่อ/ภาษาอังกฤษ, หมวดหมู่, ลิงก์เพจ, คำอธิบาย
- **เพิ่ม/ลบหน่วยงาน**: เพิ่มหน่วยงานใหม่ หรือลบหน่วยงานที่ไม่ต้องการ
- **Real-time Sync**: ข้อมูลจะซิงค์ไปยังหน้าเว็บหลักทันทีแบบ 0-delay ผ่าน `BroadcastChannel`

## 📂 โครงสร้างโปรเจกต์

```text
ku-csc-directory/
├── index.html        # หน้าเว็บหลักสำหรับผู้ใช้ทั่วไป (Read-Only)
├── editor.html       # หน้าเว็บสำหรับแก้ไขข้อมูลและเปลี่ยนรูปภาพ
├── style.css         # ไฟล์ CSS ดีไซน์ Modern Glassmorphism
├── app.js            # ตรรกะการทำงานของหน้าเว็บหลัก
├── editor.js         # ตรรกะการทำงานของหน้า Editor
├── server.js         # Local Web Server (Node.js)
├── assets/           # โฟลเดอร์เก็บรูปภาพและโลโก้ตั้งต้น
│   ├── hero_landmark_bg.jpg # รูปพื้นหลังซุ้มประตู มก.ฉกส.
│   └── ...
├── .gitignore        # กำหนดไฟล์ที่ไม่ต้องนำขึ้น Git
└── README.md         # เอกสารแนะนำโปรเจกต์
```

## 🚀 วิธีการเปิดใช้งาน

### วิธีที่ 1: เปิดใช้งานผ่าน GitHub Pages (ออนไลน์)
- เข้าใช้งานได้ผ่าน URL ของ GitHub Pages ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมใดๆ

### วิธีที่ 2: เปิดใช้งานบนเครื่อง (Local)
1. ดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ (Chrome, Edge) ได้ทันที
2. หรือรันผ่าน Node.js:
   ```bash
   node server.js
   ```
   แล้วเข้าใช้งานผ่าน:
   - เว็บผู้ใช้ทั่วไป: `http://localhost:3000/`
   - เว็บแก้ไขข้อมูล: `http://localhost:3000/editor.html`
